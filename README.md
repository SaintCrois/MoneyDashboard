# AI Investment Impact Radar

From Global Events to Investment Insights.

An AI-powered platform that analyzes global events,
business information, and financial data to identify
potential investment risks and opportunities.

## Technology Stack

- Python
- Streamlit
- FastAPI
- PostgreSQL
- Docker
- SQLAlchemy
- Pandas

## Project Structure

- client/: Frontend dashboard
- server/: Backend API
- database/: SQL scripts
